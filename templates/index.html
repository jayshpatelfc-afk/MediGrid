METHOD / TRANSPARENT LOGIC

Decision rules

How MediGrid turns mismatched extracts into a usable working view.

01

Events follow the HIS timestamp

For admissions and discharges, the HIS event time is the source of record. Manual occupancy entries remain visible as evidence, never silently overwritten.

Example13 Nov 19:42HIS event wins over 14 Nov manual entry
02

Latest verified lab result wins

When an order ID appears twice, the latest result with a verified status is used for turnaround. The duplicate remains open for review.

Example08:16 resultRetained over unverified 07:54 result
03

Occupancy is a reported snapshot

Bed sheets are treated as snapshots, not events. A stale sheet lowers confidence and is shown beside the latest movement data.

Example184 / 212Sheet value, flagged one day behind
i
Nothing is silently dropped.

Conflicts affect confidence, not visibility. Operators can always trace a working value back to the source rows that produced it.
